# Claude Code setup: what loads when

| Path                                                                                                                                                                     | Loads                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| `AGENTS.md` (through `@AGENTS.md` in `CLAUDE.md`)                                                                                                                        | Every session                                                                               |
| `rules/00-architecture`, `01-security-baseline`, `02-feature-scope`, `03-existing-template-app`                                                                          | Every session                                                                               |
| `rules/javascript`, `rules/data-and-prisma`, `shopify-api`, `admin-ui`, `seller-and-proxy-pages`, `storefront-theme`, `email-ses`, `media-s3`, `jobs-and-ops`, `testing` | Only when matching files are touched                                                        |
| `app/modules/<module>/CLAUDE.md`                                                                                                                                         | When Claude reads files in that module                                                      |
| Build skills: `start-feature`, `implement-ticket`, `close-ticket`                                                                                                        | When typed                                                                                  |
| Review skills (on demand): `review-all`, `code-review`, `security-review`                                                                                                | When typed, never automatically                                                             |
| Helper skills: `baseline-sync`, `next`, `progress`, `schema-change`, `new-module`, `add-webhook`, `add-email-template`, `shopify-graphql`, `dev-store-qa`, `ops-runbook` | When typed, or when relevant                                                                |
| Security skills: 14 module checklists (`security-<module>`)                                                                                                              | Automatically while editing that module (guidance); formal audits through the review skills |
| Agents: `feature-planner`, `test-writer` (Haiku), `code-reviewer`, `security-auditor`, `shopify-api-expert`, `docs-keeper`                                               | When delegated                                                                              |
| `settings.json`                                                                                                                                                          | Always: permissions, SessionStart progress, Prettier after edits, status line               |
| `../scripts/`                                                                                                                                                            | `progress.mjs` (status), `test-summary.mjs` (`npm run test:ai`), `format-hook.mjs`          |
| `../.mcp.json`                                                                                                                                                           | Shopify Dev MCP                                                                             |
