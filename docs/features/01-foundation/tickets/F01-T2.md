## Scope

- [ ] `transition(listingId, event, actor, payload)` implementing the whole state machine table: deadlines, pause reasons, adjustments, terminal states with `purgeAfter`, and the Phase 2 states.
- [ ] Typed event bus (`publish`, `subscribe`) that writes the audit entry before handlers run.
- [ ] `flags.isEnabled()` + release gates; `Settings` singleton with defaults (fees, time limits, photo limit, retention, held-message rules).
- [ ] Time helpers: `addMonths` in the shop timezone, deadline calculators, `adjustTime()` (technical extension, investigation restore).
- [ ] Scheduler skeleton: `/jobs/run` (bearer secret) with a task registry and a per-task result summary; tasks are added by later features.

## Out of scope

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] Every allowed transition is covered (table-driven `it.each`), and at least 10 invalid transitions or wrong actors are rejected.
- [ ] Approving a revision never changes `expiresAt` or reopens a terminal listing.
- [ ] Jan 31 + 1 month = Feb 28/29; an investigation restore adds exactly the paused minutes.
- [ ] `/jobs/run` without the secret → 401; with it → a JSON summary.
- [ ] `npm run test:ai` is green for this feature.
