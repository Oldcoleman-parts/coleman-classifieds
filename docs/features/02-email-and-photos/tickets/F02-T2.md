## Scope

- [ ] Bucket layout + Block Public Access + CloudFront OAC + a lifecycle rule for `incoming/`; a least-privilege IAM role.
- [ ] `createUploadUrl` (presigned PUT, ≤10 min, type/size/limit/token checks) and `completeUpload` (sharp: HEIC→JPEG, re-encode, strip metadata, max pixels) → `private/` + a `Photo` row.
- [ ] Previews (presigned GET), reorder, set main, delete; a browser-side resize + upload progress helper for seller and staff screens.
- [ ] `publish` (`_thumb`/`_medium`/`_large` → `public/`, CloudFront URLs), `unpublish` + invalidation, `unpublishOne` for immediate photo removal; register the 90-day retention task.

## Acceptance criteria

- [ ] A HEIC fixture with GPS ends up as a JPEG with no metadata.
- [ ] No public access to `private/`; published URLs work only through CloudFront.
- [ ] Upload is refused above `maxPhotos` or for the wrong type or size; unpublish removes the public objects.
- [ ] `npm run test:ai` is green for this feature.
