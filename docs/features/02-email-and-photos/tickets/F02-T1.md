## Scope

- [ ] `notifications.send(key, to, vars)`: SESv2 HTML + text, ReplyTo, a config set per stream, a queue with retry and backoff; suppression check before every send.
- [ ] SNS webhook (`/webhooks/ses`): signature verification, subscription confirm, hard bounce and complaint → suppression; EMAIL incident on failures or high rates.
- [ ] Rendering: liquidjs in strict mode, a per-template whitelist, HTML escaping, a shared layout from `EmailSettings`, an auto plain-text version; seed every template key from `docs/reference/email-default-content.md`.
- [ ] Settings → Emails: template list, editor, placeholder picker, preview, send test, reset, validation, versioning + audit; global settings (sender, reply-to, **staff notification address**, logo, footer, postal address).
- [ ] `notifyStaff(kind, listing, link)` for NEW, CORRECTED, EDIT and MESSAGE_HELD, subscribed to the matching events.
- [ ] Write `docs/reference/ses-setup.md` (DKIM, MAIL FROM/SPF, DMARC, production access).

## Out of scope

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] A suppressed address is skipped; simulator bounce and complaint create suppressions; a bad SNS signature → 403.
- [ ] A template edit applies to the next send; removing a required placeholder is blocked; reset restores the default.
- [ ] Each of the 4 staff-notice triggers sends one email with the title and a working review link.
- [ ] `npm run test:ai` is green for this feature.
