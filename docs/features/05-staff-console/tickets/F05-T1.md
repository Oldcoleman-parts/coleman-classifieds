## Scope

- [ ] Listing list: status tabs with counts, search, columns (listing, seller, status, fee state, ends).
- [ ] Review screen: public preview, private seller details, photos (remove, reorder, set main), inline wording edit; Approve, Request changes (note + correction deadline), Reject (reason).
- [ ] Revision side-by-side comparison with approve or reject edit (never changes `expiresAt`).
- [ ] Pause (with a reason), Resume (investigation outcome), Extend (days + reason); payment panel with charges, periods and adjustments.

## Out of scope

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] Counts match the DB; every action is audited with the staff email.
- [ ] Request changes emails the seller and reopens the form; Reject closes the link with nothing charged.
- [ ] An ordinary pause keeps `expiresAt`; an investigation with no violation restores exactly the paused time; an extension is recorded.
- [ ] `npm run test:ai` is green for this feature.
