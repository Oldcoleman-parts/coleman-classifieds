Start with `/implement-ticket F05-T3`. Requested by the client (2026-10-27): the History screen today is only an export form; staff want to see the entries on screen, filter them, and export what they see.

## Scope

- [x] `/app/history` shows the history entries as a list, newest first, 50 a page (next/previous): time (shop timezone), listing (link to `/app/listings/:id`, or "—"), action, who (actor type, plus the staff email for STAFF), and the one-line summary the listing timeline already uses (status change, note or reason).
- [x] Filters, kept in the URL query so a filtered view can be shared or reloaded: date range (default the last 30 days, at most 366 days), listing id, action (a list of the actions present), actor type (Staff, Seller, System…), staff email. All optional and combinable; invalid values show a field error, never a server error.
- [x] "Export CSV" exports exactly the filtered entries (all pages), through the existing streamed, injection-safe export (`streamHistoryCsv`), which takes the same filter. Each export is still recorded in the audit log. The listing-only export from a listing's page keeps working.
- [x] The admin nav link reads "History" and points to `/app/history`; `/app/history/export` redirects there (keeping `listingId`).
- [x] Read-only: nothing changes or deletes an entry. Seller and buyer personal data isn't added to the list (the `details` column stays in the CSV only, as today).
- [x] Update the F05 README (routes, business rules) and `app/modules/console/CLAUDE.md`.

## Out of scope

- Free-text search inside `details`.
- Any change to what is written to the audit log.
- Anything listed in other tickets or features.

## Acceptance criteria

- [x] With entries across dates, listings, actions and actors, each filter (and a combination) returns only the matching entries, newest first, 50 a page (test).
- [x] The export with filters contains exactly the filtered entries, and writes one export audit entry (test).
- [x] Invalid filters (a bad date, an end before the start, a range over 366 days, an unknown actor type) give a field error (test).
- [x] The page needs a Shopify admin session (test).
- [x] `npm run test:ai -- app/modules/console` is green.
