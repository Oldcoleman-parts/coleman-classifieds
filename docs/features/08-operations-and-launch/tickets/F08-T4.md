Start with `/implement-ticket F08-T4`.

## Scope

- [ ] Migration `audit_purge_past_retention`:
  - replaces `audit_event_append_only()` so the `classifieds_purge` role may `DELETE` an `AuditEvent` only when `OLD.at <= now() - recordsRetentionDays` (from `Settings`, default 365) or when its listing has `purgeAfter <= now()`; everything else is still rejected (`42501`);
  - adds `GRANT SELECT ON "Settings" TO classifieds_purge`.
- [ ] Hourly task `ops.purge-records` (time box 300 s, at most 50 listings per run):
  - candidates are listings with `purgeAfter <= now` and `closedAt` set, including closed `INVITED` records;
  - skip a listing while its photos aren't deleted yet or `metaobjectGid` is still set;
  - one transaction per listing with `SET LOCAL ROLE classifieds_purge`, deleting in this order: `AuditEvent`, `Photo`, `ListingRevision`, `ListingTimeAdjustment`, `ListingPeriod`, `FeeCharge`, `TermsAcceptance`, `BuyerMessage`, `Listing`, `EmailCode`, `Invitation`.
- [ ] Global audit retention: delete listing-less `AuditEvent` rows past retention, except `SettingsUpdated` rows whose `rulesVersion.to` is referred to by a kept `TermsAcceptance` (or is the current version).
- [ ] One `RecordsPurged` audit entry per run (counts only).
- [ ] Update `docs/architecture/data-model.md` (trigger, grants) and `app/modules/core/tests/audit-append-only.test.js`.

## Out of scope

- The 90-day photo deletion (already `media.purge-closed-photos`, F03-T2).
- Deleting old metaobjects and creating redirects (F08-T1).
- Privacy redact erasure (F08-T5).
- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] A listing past `purgeAfter` (and a closed `INVITED` record) leaves no rows in any table.
- [ ] Rows before `purgeAfter` are untouched (SEC).
- [ ] The purge role can't delete a recent audit row, and the app role can't delete any (SEC).
- [ ] A listing with audit rows deletes without a trigger error.
- [ ] A rules version referred to by a kept `TermsAcceptance` survives.
- [ ] Two runs have one effect.
- [ ] `npm run test:ai` is green.
