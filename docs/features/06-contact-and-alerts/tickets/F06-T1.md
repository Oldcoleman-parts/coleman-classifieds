## Scope

- [ ] Contact form (name, email, message ≤ 2000, Turnstile, honeypot); rate limits per IP, email and listing; LIVE only.
- [ ] The hold classifier from `Settings.heldMessageRules`; `BuyerMessageHeld` → instant staff notice; release (sends once) and discard actions used by the F04 messages screen.
- [ ] Relay via `buyer_message` (ReplyTo = buyer, CR/LF stripped); logged with the SES message ID.

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] A normal message reaches the seller and replies go straight to the buyer; the seller email never appears in the HTML.
- [ ] A message with a link is held, staff are emailed with a working link, release delivers it once, and discard never delivers.
- [ ] Bots and rate-limited sends are rejected; a closed listing refuses messages.
- [ ] `npm run test:ai` is green for this feature.
