## Scope

- [ ] The signup block (browse page) + a standalone shareable page (works with 0 listings); Turnstile + rate limit; a neutral response (no enumeration).
- [ ] Confirm, unsubscribe (one-click + `List-Unsubscribe-Post`) and the unsubscribed page with resubscribe.
- [ ] Enqueue on `ListingWentLive(firstTime)`; a daily digest task (max 10 + “and N more”) through the `alerts` config set; a complaint → unsubscribe; console count + CSV export.

## Out of scope

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] Unconfirmed addresses never receive a digest; unsubscribe works from Gmail’s button.
- [ ] No email on days without new listings; edited or re-published listings aren’t re-sent.
- [ ] The flag off hides the signup and pauses digests.
- [ ] `npm run test:ai` is green for this feature.
