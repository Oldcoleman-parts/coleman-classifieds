## Scope

- [ ] `createInvitation()` (a transaction with the Listing; fee prefilled from promo/base and editable; offer scope) and the **Create invitation** screen: seller details, item summary, fee, offer scope, staff photos (F02 helper), the seller’s previous listings, and a copyable link + invitation email.
- [ ] `resolveToken()` (constant time; invalid, closed or expired states) and revoke; the 30-day expiry task registered with the scheduler.
- [ ] Email code check (when `emailCodeRequired`): 6 digits, 15 min, max 5 attempts, a signed device cookie for 30 days.

## Out of scope

- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] A modified token shows the invalid page; a second listing per invitation is impossible.
- [ ] A later Settings fee change doesn’t change a locked invitation.
- [ ] A forwarded link on a new device can’t proceed without the code; brute force is locked after 5 attempts.
- [ ] Tokens and codes never appear in logs.
- [ ] `npm run test:ai` is green for this feature.
