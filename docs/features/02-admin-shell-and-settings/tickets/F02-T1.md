## Notes

**Decisions**

- **Online tokens:** `useOnlineTokens: true` was added to `app/shopify.server.js` (approved by the developer, 2026-10-05). Admin requests now carry the logged-in staff user, which the audit log needs because OCP has several staff users. The offline token is still stored for webhooks and jobs. The dev store re-authenticates once.
- **Staff actor:** `core.staffFromSession(session)` builds the actor from `session.onlineAccessInfo.associated_user.email` and throws `UnauthorizedError` when there is none. Every admin action uses it.
- **Audit:** a save writes one `SettingsUpdated` audit entry with `details.changes = { field: { from, to } }`. It is not a bus event.
- **Whitelist:** `core.updateSettings()` refuses any key outside the nine editable settings instead of dropping it, so rules text, feature switches and Shopify ids can’t be changed through it.
- **Promotional fee:** blank means none; a promotional fee above the base fee is refused (not in the spec).
- **Limits not in the spec:** flagged words up to 50, 60 characters each, lower-cased and de-duplicated; repeated sends 1–20; fees up to $1,000,000 (the existing `requireCents` cap).

**Manual QA (dev store, 2026-10-05, by the developer):** the app opens with the new navigation after `useOnlineTokens` was switched on; on Settings, the save bar and the “Settings saved” toast work.

**Differences from the template:** `app/shopify.server.js` (`useOnlineTokens`), `app/routes/app.jsx` (one nav link), `app/routes/app._index.jsx` (demo replaced by a plain home page), `app/routes/app.additional.jsx` (removed).
