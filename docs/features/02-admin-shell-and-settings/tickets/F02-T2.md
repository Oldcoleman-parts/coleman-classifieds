## Scope

- [ ] Listing rules editor on the Settings screen: rules text (sanitised) with the current version shown; saving a changed text bumps `rulesVersion` through `core.updateSettings()`.
- [ ] Features card (`/app/settings/features`): the alerts switch, plus renewals and open submissions only when `isReleased()`; a confirmation modal when turning a feature off; saves through `core.setFlag()` (`FeatureToggled`).

## Out of scope

- What each feature does when its flag changes (F07 alerts, F09 renewals, F10 open submissions).
- Anything listed in other tickets or features.

## Acceptance criteria

- [ ] Editing the rules text bumps the version and is audited; saving unchanged text doesn’t bump it.
- [ ] Toggling alerts writes `FeatureToggled` with the staff email; unreleased features show no switch and can’t be turned on by a crafted request.
- [ ] `npm run test:ai` is green for this feature.
